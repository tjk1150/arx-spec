# ARX 0.1 Conformance 결과

기준: `0.1.0` (2026-10-16). 양성 fixture 19개, 음성 fixture 18개, 효과 묶음(`fixtures/effects/`의 E 5개·D 9개)을 검증기 셋(TS·Swift·Kotlin)에서 확인했다. 모든 칸의 판정은 아래 "시험 위치와 다시 돌리는 명령" 절의 시험 이름과 실행 결과에 근거한다. spec, fixture, 구현이 서로 어긋나는 곳은 없다. 규범 밖의 구현 차이는 끝에 따로 적는다.

## 규범 밖의 구현 차이

fixture 결과에는 영향이 없고 spec이 정하지 않은 부분이다. 필요하면 다음 버전에서 spec이나 fixture로 고정한다.

| 항목 | TS | Swift | Kotlin |
|---|---|---|---|
| 리다이렉트 검사 | 최종 URL만 (spec 7 MUST 충족) | 최종 URL만 | 매 단계 요청 전에 검사 |
| 사내 배포 모드의 기본 fetcher 정책 | 기본 정책 | 기본 정책 | 호출자가 준 정책 |
| 미선언 확장 경고 순서 | manifest 순서 | 이름순 | manifest 순서 |
| 쿼터니언 정규화 | 노름이 1이 아닐 때만 | 항상 | 항상 (차이는 1 ulp 이하) |
| DNS rebinding | 막지 않음 | 막지 않음 | 막지 않음 (spec 7 SHOULD, 구현의 네트워크 계층 몫) |
